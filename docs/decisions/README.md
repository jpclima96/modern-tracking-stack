# Architecture Decision Records (ADRs)

Registro das decisões arquiteturais do projeto. Cada ADR é imutável depois de
aceito; para mudar uma decisão, crie um novo ADR que a substitua (`Supersedes`).

| ADR | Título | Status |
|-----|--------|--------|
| [0001](./0001-warehouse-e-transformacao.md) | Warehouse (BigQuery) e transformação (dbt) | Aceito |
| [0002](./0002-tracking-contract-first.md) | Tracking contract-first | Aceito |
| [0003](./0003-ambiente-offline.md) | Ambiente offline por padrão | Aceito |
| [0004](./0004-airbyte-real.md) | Airbyte como conexão real e versionada | Aceito |

Formato de cada ADR: **Contexto → Decisão → Consequências → Alternativas**.
